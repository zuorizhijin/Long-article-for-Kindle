零云盘、零亚马逊依赖的本地长文章与电子书同步系统（Chrome 扩展 + Python 局域网服务 + KOReader 插件）


        


        

          点击上方步骤卡片或按钮逐步浏览完整链路
          

            
            
          

        

      


      

        

          v1.1.0 核心亮点
          
    
            
  • 电子书局域网直传：直接拖入 sync_server/data/books/，支持大文件 64 KiB 分块流式下载。
    • 
            
  • Obsidian 多选批量同步：复选框多选 / 全选当前筛选结果，顺序转 EPUB 并实时显示进度。
    • 
            
  • 原生弹窗选/建分类子文件夹：无需手打路径，文章与电子书均支持任意子目录原样同步。
    • 
            
  • Kindle 主页 5 键直达：文章、电子书、已读、一键全部同步、同步地址一屏搞定。
    • 
          

        

        

          目录一一对应关系
          
电脑端 sync_server/data/         Kindle /mnt/us/documents/
├── inbox/（含子文件夹）   ──▶   ├── 文章/（自动建同级子目录）
├── read/ （保留分类归档） ◀──   ├── 已读/（读完自动移入并回传）
└── books/（含子文件夹）   ──▶   └── 电子书/（长期保留不移走）

          KOReader 电子书格式支持清单
          
    
            
  • 完美推荐：无加密 EPUB、TXT、MD、DOCX、RTF、HTML、FB2、CHM
    • 
            
  • 原生可用：PDF、DjVu（支持裁边重排）、无加密 MOBI、漫画包 CBZ / CBR
    • 
            
  • 不支持（服务端自动过滤）：亚马逊专有 AZW3、KFX 及任何带 DRM 加密文件
    • 
          

        

        

          删除与归档机制（单向只增不删，保护笔记）
          
    
            
  • 正常看完的长文章：读到末页点「移至已读」，Kindle 移入 已读/ 并回传电脑归档到 read/；此后删 Kindle 绝不再重下。
    • 
            
  • 未读完想删的长文章：电脑 data/inbox/ 与 Kindle 文章/ 两边删除即可。
    • 
            
  • 看完想删的电子书：电脑 data/books/（删除或移走备份）与 Kindle 电子书/ 两边清理即可。
